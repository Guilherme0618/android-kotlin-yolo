O aplicativo foi desenvolvido para permitir que o usuário selecione uma imagem da galeria do celular e execute uma deteccao de objetos diretamente no dispositivo. 
Após a seleção da imagem, o app converte o arquivo escolhido para um formato que possa ser processado pelo modelo, 
prepara essa imagem de acordo com a entrada esperada pelo YOLO e realiza a inferência usando TensorFlow Lite.
